# 文档

- [架构](architecture/README.md)：当前领域职责、必要语义、接口边界和支持范围。从[总览](architecture/ARCHITECTURE.md)开始。
- [语义验收](architecture/verification.md)：从架构契约推导的关键结果及测试归属。
- [原生研究](research/00-INDEX.md)：机制结论、实际使用例、证据与未决问题。
- [测试说明](../test/README.md)：测试组织和运行方式。

架构描述当前设计，不保存讨论过程或废弃方案；原生研究描述证据，不另维护一套项目架构。公共协议集中说明，领域文档只补充自身差异。接口的完整声明以源码为准，文档解释职责、约束和可观察结果。

行为改变时同时核对原生依据或明确的项目选择、所属架构契约和必要测试。历史代码、既有测试和“以后再接内容”都不能替代缺口判断；证据不足、尚未实现和明确不支持分别说明。
