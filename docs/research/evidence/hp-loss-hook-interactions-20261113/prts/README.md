# 生命流失与增减伤：实际内容对照

查阅日期：2026-11-13。仅回答真实内容是否要求区分普通伤害、生命流失及公式修正；不修改 Core、测试或案例 11，不根据原生事件调用次数设计 API。

## 1. “睚”与铃兰：普通真实伤害和真实流失的实际差别

[“睚”当前正文](https://prts.wiki/w/睚)在级别 0 的第二形态能力中明确区分同一个触发：妄境退场时，本体未消失则受到最大生命 35% 的真实伤害；本体正在消失则流失最大生命的 35%。定位：级别 0 → 天赋与能力 → 第二形态；本次浏览文本行 271–273，后续等级也有同样描述。

[2023-01-25 的 PRTS 讨论](https://prts.wiki/w/话题:Xbcmlizcauhbcdc7)提供实际配队场景：WB-EX-8 中使用铃兰、能天使，分身死亡后本体的扣血超过提问者按 35% 计算的结果；回复指出铃兰脆弱会放大未消失时的普通真实伤害，并给出 `35% × 1.4 = 49%` 的解释，消失时改为流失。

证据分档：普通伤害／流失两分支是当前 Wiki 正文；49% 对 35% 是历史玩家反馈与社区解释，本批未重放视频或执行客户端，也未重新验证消失期间铃兰光环的全部保留时序。它是实际内容对照，不是两个 LOSS 之间的来源计算 Hook 反例。

对统一 HP Damage 模型的意义：同为真实类型，`DAMAGE` 与 `LOSS` 需要不同的普通增伤参与条件；`nature` 可以表达这个差别。流失分支还说明不能直接沿用普通空间存在资格来拒绝已消失的目标。

## 2. 拟态机械射线与淬羽赫默：法抗仍参与，庇护不参与

[拟态机械](https://prts.wiki/w/拟态机械)的“链式反应”射线是每秒攻击力 50% 的法术生命流失。正文定位：级别 0 → 技能 → 链式反应，本次浏览文本行 250–261。其实际关卡及 `AdvancedApplyDamage(MAGICAL, skip=true)` 绑定复用[本轮原生与配置证据](../../hp-loss-settlement-20261113/README.md)。

[淬羽赫默](https://m.prts.wiki/w/淬羽赫默)普通天赋为范围内友军提供庇护；[作战机制的伤判章节](https://prts.wiki/w/作战机制#伤判效果与生命流失)说明生命流失不受普通脆弱／庇护等伤判增减伤影响，但物理／法术公式仍读取防御属性。两者可以在通常主线编队中同时出现，无须借用不支持的模式或拼接不可能共存的敌人。

因此，这个射线的损失量仍会随接收者 RES 改变；赫默提供的普通庇护不应再乘一次减伤。此处结论由实际技能、庇护定义及已核对的 skip 路径组合得到，**不是本次测量的一局战斗**。它区分属性公式与伤判减伤，仍然支持通过 `nature` 在公共 Calculate／Apply 中选择业务，不证明必须分出另一套 Damage 系统。

## 3. 没有找到的反例

本轮没有找到已验证的真实场景，证明**两笔同属 LOSS 的输出，仅因一笔派发来源计算事件、另一笔不派发，就产生重要玩法差别**。

已有 native 调查确实发现不同节点的计算事件参数不同，但未补齐“具体修正同时存在、该修正确实接受这笔流失、最终伤害或后继发生变化”的内容链。不能把节点名、调用次数或一个理论上可挂的 Hook 当作实战反例。

同样，攻击力或法抗变化影响流失公式，不等于证明某个来源 Formula Hook 参加了计算。当前证据不足以因此要求在 `nature` 之外增加计算模式字段，也不足以宣称全部流失永远具有相同计算响应；项目可先依据已证内容设计，保留这项证据边界。

## 4. 辅助资料与排除

- [领主·Sharp](https://prts.wiki/w/领主·Sharp#模组)的模组备注明确把附加法术伤害称为生命流失，并说明可越过普通减伤／屏障。但该页是卫戍原型资料，获得方式标为无；本批未验证实际可用入口，**不用它证明普通关卡能组成的实战场景**。
- [百炼嘉维尔](https://prts.wiki/w/百炼嘉维尔#技能)三技能明确将实际拦下的伤害记录，结束后按 20 秒生命流失返还。这证明记录数额与后续流失是两个业务事实；本轮没有据此虚构一套会重复放大的共存 Buff。
- 《游戏数据基础》的流失概览笼统写到不触发来源计算事件，而本轮 native 节点参数已证明不能将该概括推广到每条入口。因此以“当前没有内容反例”作为限制，不将 Wiki 的概览文字当作全部计算路径证明。
